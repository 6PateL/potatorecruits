# Potato Recruits

Сабмод для Recruits + Create (Forge 1.20.1). Рекрути можуть стріляти з картопляної гармати Create.

## Як користуватись
1. Відкрийте інвентар рекрута (Recruits, як зазвичай).
2. У слот правої руки покладіть **Potato Cannon**.
3. У рюкзак рекрута покладіть набої: картопля, печена картопля, яблуко, морква, буряк тощо, як у звичайної гармати Create.
4. Рекрут стріляє по цілях на відстані до 24 блоків. Якщо гармата лежить у рюкзаку, він візьме її в руку сам.

Працює для будь-якого рекрута, також для лучників та арбалетників.

## Конфіг `potatorecruits-common.toml`
range, minIntervalTicks, consumeAmmo, damageCannon, avoidFriendlyFire.

## Збірка
Завантажити у GitHub, Actions збере jar. Файли Create і Recruits лежать у `libs/`.
